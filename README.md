# Tobu TEG Navigator

Tobu TEG Navigatorは、TEG GH / TEG PM の測定値をもとに、院内プロトコールに沿って解釈と次に検討すべき対応を表示する医療者向け意思決定支援アプリです。

Created by Kosei Omasa

---

## 目的

TEGの解釈に慣れていない医療者でも、測定値から以下を整理できるようにすることを目的とします。

- TEG GH / TEG PM の使い分け
- 凝固因子不足
- ヘパリン影響
- フィブリノゲン不足
- 血小板数・血小板機能低下
- 線溶亢進
- 外傷時の輸血戦略
- ECMO中の抗凝固管理の補助
- MTP de-escalation候補の確認

---

## 重要な注意

このアプリは院内医療者向けの意思決定支援ツールです。

- 治療を自動決定するものではありません。
- 最終判断は担当医が行ってください。
- TEGはPOCTであり、実際の投与・投与量は現場判断です。
- TEGのために止血処置、輸血が遅れてはなりません。
- 患者氏名、患者ID、生年月日、診療録番号などの個人情報は入力しないでください。

---

## 入力方式

本アプリではOCR機能は使用しません。

TEG画面の値は医療者が確認し、手入力します。
これはOCR誤読による誤判定を避けるための安全設計です。

---

## 採血管

### TEG GH

TEG GHでは、以下を使用します。

- 3.2%クエン酸ナトリウム加採血管
- 青スピッツ
- 凝固検査用スピッツ

### TEG PM

TEG PMでは、以下を使用します。

- ヘパリン加採血管
- 緑スピッツ
- Platelet Mapping用スピッツ

アプリ上では、GH/PM選択時および入力画面上部に、採血管のイラストと正式名称を表示します。

---

## 主な機能

- GH / PM選択支援
- 採血管表示
- TEG GH手入力
- TEG PM手入力
- GH一般解釈
- 外傷TTP解釈
- 頭部外傷PM解釈
- 抗血小板薬PM解釈
- ECMO GH解釈
- 結果カード表示
- 色分け表示

---

## 結果表示の色分け

- 赤：明確な異常・介入検討
- 黄：Expert判断・参考解釈・MTP de-escalation候補
- 緑：正常範囲・目標範囲内
- 灰：未入力・未評価

---

## 結果カード見出し

- 赤カード：【異常】〇〇
- 黄カード：【要判断】〇〇
- 緑カード：【範囲内】〇〇
- 灰カード：【未評価】〇〇

## GitHub Pagesでの公開

このリポジトリは、`index.html` と `assets/` の静的ファイルだけで表示できます。

1. GitHubのリポジトリ設定で `Settings > Pages` を開く
2. Sourceを `Deploy from a branch` にする
3. Branchを `main`、Folderを `/root` にする
4. 保存後、表示されるGitHub Pages URLにアクセスする

参考資料そのものは公開対象に含めず、必要な内容のみアプリ内に反映しています。

## データ管理

本アプリは患者情報を保存しません。
画像アップロード、カメラ撮影、OCR機能は使用しません。
測定値はブラウザ上で一時的に扱うのみとし、サーバー保存は行いません。
